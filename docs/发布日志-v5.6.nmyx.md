# v5.6.nmyx 发布日志（2026-11-16）

> 接棒方：DeepSeek Harness（deepseek-v4.1-flash-1017）· 上一版 v5.5.nmyx（提交 0fc8016）

## 一、这一版做了什么

把底部悬浮导航栏从「半透明色板」换成**液态玻璃**（Liquid Glass）：真实模糊背后内容 +
圆角边缘透镜折射（带轻微色散）+ 顶部高光 / 亮描边 / 内侧暗影 + 选中页签是一片会滑动的玻璃胶囊。

实现方式：引入第三方库 `io.github.kyant0:backdrop:2.0.1`（Apache-2.0，
GitHub: [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)，作者 Kyant），
使用它的 `Modifier.drawBackdrop` + `blur` / `lens` / `vibrancy` 效果；
不再使用内部早期自研的光学绘制层。

## 三、关键实现要点（下一手改底栏前必看）

1. **三层 backdrop**：`bgBackdrop`（背景层）+ `contentBackdrop`（页面内容层）合成
   `barBackdrop`；底栏 Row 上再挂 `layerBackdrop(barLayer)` 记录「含图标」的画面。
   面板用 `barBackdrop`，**胶囊用 `barLayer`** —— 胶囊若用 `barBackdrop` 会把图标整个盖住。
2. **背景要有「可折射的材料」**：深色主题 + 无壁纸时页面背景是纯色，
   玻璃与背景同色（实测 #2C261E vs #2E241A），完全看不出玻璃。所以无壁纸分支底部叠了一层
   `Brush.verticalGradient(0.52f → 0.84f primary@10% → 1.0f primary@20%)` 的柔光。
   删掉这层，深色下液态玻璃就消失了。
3. **颜色要在 @Composable 作用域取**：`onDrawSurface = { drawRect(capsuleTint) }` 里的
   `DrawScope` 不能调 `MaterialTheme.colorScheme`（编译不过），必须在外面先算好变量。
4. **按压观察不能消费事件**：`pointerInput` 里用 `PointerEventPass.Initial` 只读不消费，
   否则底栏 Tab 点不动。
5. 交接文档 §7.1 的约束仍然有效：底栏是悬浮 overlay、内容穿透是设计，
   **不要为了让玻璃能折射列表内容而给页面加 bottom padding**。

## 六、已知限制 / 留给下一手

1. **设置页那个开关我在真机上点不动**（同卡片上方「全局亚克力」行能点，这一行坐标没命中），
   所以「关掉后回退纯色面板」这条分支只做了代码复核，没有真机验证。请手动点一次确认。
2. **无壁纸时折射变形有限**：玻璃只能折射背景纯色 + 底部柔光，看不出「内容被弯折」的效果；
   想要更强的折射，唯一办法是让内容真正滚到底栏下方（与 §7.1 冲突，不要做）。
3. **性能未测**：每帧跑 RuntimeShader（blur + lens），中低端机的耗电/发热没有数据。
   如果用户反馈卡顿，先降 `blur` 半径或去掉 `lens`，再考虑关开关默认值。
