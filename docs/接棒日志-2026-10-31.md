## 六、留给下一手

1. **`.toolchain/env.ps1` 必须保持 UTF-8 带 BOM**。本机是 Windows PowerShell 5.1，
   没有 BOM 时会按 GBK 解码，中文注释会吞掉换行，脚本断在注释后面、后面的赋值全部不执行。
   改完 `.ps1` 请验证前 3 字节是 `EF BB BF`。
2. dot-source 脚本要用**绝对路径**（相对路径会被当成 cmdlet）；且需要先
   `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force`。

## 七、v5.8.nmyx（2026-11-23）：教务课表导入修对了

用户反馈（v5.7 刚上线的账号登录导入）：「课程时间是错误的」「课表位置没错但是上课时段是错误的」。
两条都是真 bug，根因也都在代码里，不是学校页面变了。

### 根因

1. **默认作息是自己估的**。`PeriodTable.DEFAULT_TIMES` 原来是一天 11 节、每节 40 分钟，
   而金山校区实际是 45 分钟一节、一天 12 节，且**第 2、3 节之间还夹着 09:35-09:55 的课间**
   （第 3 节从 09:55 开始）。旧值纯属当年按「理想作息」编的，全错。
2. **解析器在看表格列号**。它按表头列号推星期、按行序推节次，而正方 V6 的 `xskbcx.aspx`
   大量使用 `rowspan` / `colspan`：第 1 节的单元格竖着合并到第 2 节，一行里的 `<td>` 数
   从 4 到 9 不等，**列号与星期根本不一一对应**，于是星期/节次整体错位。

### 改动

| 文件 | 改了什么 |
|---|---|
| `schedule/ScheduleStore.kt` | `DEFAULT_TIMES` 换成官方 12 节；新增 `LEGACY_DEFAULT_TIMES` + `MIGRATION_LEVEL = 1` 一次性迁移，只有存值与旧默认**一字不差**才换新（用户自己调过的作息不动） |
| `schedule/ZfsoftParser.kt` | 新增 `parseAnchored`：以每门课自带的「周四第1,2节{第7-8周}」行作为锚点，星期取字符、节次取区间、周次取花括号、课程名取上一行、教师与地点取紧邻两行，**完全不看列号**；新版 `/jwglxt` 把「周X第a,b节」塞进花括号的格式跳过锚点、交给原来的网格逻辑兜底；保留 `parseByGrid` 兼容其它版本 |
| `schedule/CaptchaImage.kt` | 新增：保留原色、**不做二值化**（二值化会把 6 认成 J、k 认成 x，实测坑过一整轮），只按整数倍放大 |
| `schedule/ZfsoftImportScreen.kt` | 验证码按物理像素整数倍放大显示（`FilterQuality.None`）；输入过滤 `isLetterOrDigit` → 「去空白」（学校验证码含符号）；失败路径改为 `refreshCaptcha(clearError = false)` 再写 `error` |
| `schedule/ZfsoftClient.kt` | 新增 `sitePath(relative)`：`prefix` 为空（金山学院无会话前缀）时补一个斜杠，修掉 `http://jsxyjwgl.fafu.edu.cnxskbcx.aspx` 这类非法地址；类注释改正「两个站点的会话机制不一样」 |

### 为什么「失败原因看不见」也是 bug

`submit()` 的 catch 里先调 `refreshCaptcha()` 再写 `error`，而 `refreshCaptcha()` 第一行就是
`error = ""` —— 服务端返回的「验证码不正确！！」被自己抹掉了，用户只看到验证码图静默换一张。

### 本轮踩到的新坑（留给下一手）

1. **PowerShell 执行策略禁止直接运行 `.ps1`**（本机提示「未对文件进行数字签名」）：
   必须 `powershell.exe -ExecutionPolicy Bypass -NoProfile -File <脚本> <参数>` 起子进程，
   dot-source 与 `&` 调用都会被拦。
2. **真机装包 MIUI 拦截**：`adb install` 会弹「USB 安装提示」，需 Start-Process 起 adb install
   （APK 路径必须加引号，工作区路径带空格）→ sleep 6 → `adb shell input tap 1421 1229` → sleep 30；
   `install -r` 后必须 `am force-stop` 再 `am start`，否则跑的还是旧进程。
3. **验证码识图**：先把 GIF 拉下来（debug 包 `run-as` 读 `files/`）再用 `System.Drawing`
   整数倍最近邻放大看，比截图猜快得多；二值化一定别用。
4. **抓真机页面 HTML**：`adb exec-out run-as com.campusglass cat files/x.html > x.html` 在 PowerShell
   里会把输出写成 UTF-16（长度翻倍、`<tr>` 一个都搜不到），要用 python `subprocess` 取 bytes 落盘。
